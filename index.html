1. Düzxətli bərabərsürətli hərəkət

Cisim bərabər zaman fasilələrində bərabər yerdəyişmələr icra edir; sürətin modulu və istiqaməti dəyişmir (a = 0).

🔎
v=St v=x - x₀t v=tgα
v — sürət (m/s), S — gedilən yol / yerdəyişmə (m), x - x₀ — koordinat dəyişməsi, t — zaman (s), tgα — S(t) qrafikinin meyl bucağı (α₁ > α₂ > α₃ ⇒ v₁ > v₂ > v₃)
|S|=v · t
Bərabərsürətli hərəkətdə yerdəyişmənin ədədi qiyməti (modulu)
l=v · t
Sabit sürətlə hərəkət edən cismin qət etdiyi yolun düsturu
x=x₀ + Sₓ x=x₀ + vₓ · t
Hərəkət tənliyi: x — son koordinat, x₀ — başlanğıc koordinat, Sₓ — yerdəyişmənin proyeksiyası
l=|S|
Düzxətli bərabər sürətli hərəkətdə gedilən yol (l) yerdəyişmənin moduluna (|S|) bərabərdir
l>|S|
Düzxətli dəyişənistiqamətli və əyrixətli hərəkətdə gedilən yol yerdəyişmənin modulundan böyükdür
km/s=m/s : 3,6 m/s=km/s · 3,6
Sürət vahidlərinin çevrilməsi: km/saat-dan m/s-ya keçmək üçün 3,6-ya bölünür; m/s-dan km/saat-a keçmək üçün 3,6-ya vurulur
v_yol=S_yolt v_yerdəyişmə=S_yerdəyişmət
Yola və yerdəyişməyə görə orta sürətlərin tapılması
v_or=v₁ + v₂ + v₃3
Cisim zamanın birinci 1/3, ikinci 1/3 və üçüncü 1/3 hissəsini uyğun olaraq v₁, v₂, v₃ sürətlə gedirsə orta sürət
v_or=2v₁v₂v₁ + v₂ v_or=3v₁v₂v₃v₁v₂ + v₂v₃ + v₁v₃
Yolun iki bərabər (1/2) və ya üç bərabər (1/3) hissəsini fərqli sürətlərlə gedərkən orta sürət
v₁,₂(→)=v₁(→) - v₂(→) v₂,₁(→)=v₂(→) - v₁(→)
Vektorial nisbi sürət: v₁,₂(→) — 1-ci cismin 2-ciyə nəzərən sürəti; v₂,₁(→) — 2-ci cismin 1-ciyə nəzərən sürəti
v₁,₂=v₁ - v₂ v₂,₁=v₂ - v₁
İki cisim bir düz xətt üzrə eyni istiqamətdə hərəkət edərkən nisbi sürətlərin proyeksiyaları
v₁,₂ = v₂,₁=v₁ + v₂
Cisimlər əks istiqamətlərdə və ya qarşı-qarşıya hərəkət edərkən nisbi sürətin modulu
v₁,₂ = v₂,₁=√(v₁² + v₂²)
Cisimlər bir-birinə perpendikulyar (90°) istiqamətdə hərəkət edərkən nisbi sürətin modulu
v₁,₂ = v₂,₁=√(v₁² + v₂² - 2v₁v₂cosα)
Cisimlər aralarında α bucağı əmələ gətirərkən nisbi sürətin modulu (kosinuslar teoremi)
v_yer=v_s + v_e v_yer=|v_s - v_e|
Eskalator məsələləri: sərnişinin yerə nəzərən sürəti (eyni istiqamətdə +, əks istiqamətdə fərq; v_s > v_e olarsa öz istiqamətində, v_s < v_e olarsa eskalator istiqamətində hərəkət edir)
t=dv_y Sₓ=(vₓ + v_ç) · t
Çayın keçmə müddəti (d — çayın eni, v_y — y oxu üzrə sürət toplananı) və üzgüçünün üfüqi yerdəyişməsi
v_axın ilə=v₁ + v₂ v_axın əksinə=|v₁ - v₂|
Çay axını istiqamətində və axının əksinə hərəkət edən qayığın sahilə nəzərən sürəti (v₁ — çaya nəzərən sürət, v₂ — axın sürəti)

2. Düzxətli bərabərtəcilli hərəkət

Cisim bərabər zaman fasilələrində sürətini eyni qədər dəyişir; təcil sabit qalır (a = const).

🔎
a=ΔvΔt a=v - v₀t a=tgα
a — təcil (m/s²), v₀ — başlanğıc sürət, v — son sürət, t — zaman, tgα — v(t) qrafikinin meyl bucağı (α₁ > α₂ > α₃ ⇒ a₁ > a₂ > a₃)
v=v₀ ± a·t v=√(v₀² ± 2aS)
Sürətin modulu: bərabəryeyinləşəndə (+), bərabəryavaşlayanda (-) götürülür
l = S=v₀·t ±a·t²2
Yol və yerdəyişmə modulunun zamandan asılılığı (+ yeyinləşən, - yavaşlayan)
S=v² - v₀²2a S=v + v₀2· t
Zamansız və orta sürətli yol/yerdəyişmə düsturları (yavaşlayanda sürətlər fərqi v₀² - v² olur)
x=x₀ ± v₀·t ±a·t²2
Bərabərtəcilli hərəkətdə koordinatın zamandan asılılıq tənliyi
v=a·t S=a·t²2
Sükunət vəziyyətindən başlayan (v₀ = 0) hərəkətdə sürət və yol düsturları
Sₙ=v₀ ±a·(2n - 1)2
n-ci saniyədə gedilən yol (+ yeyinləşən, - yavaşlayan; v₀ = 0 olduqda Sₙ = a·(2n - 1) / 2)
t_dayanma=|v₀a|
Bərabəryavaşlayan hərəkətdə cismin tam dayanmasına (v = 0) sərf etdiyi zaman
v_or=S_ümumit_ümumi
Ümumi orta sürət: (S₁ + S₂ + ...) / (t₁ + t₂ + ...)
v_or=v₁t₁ + v₂t₂t₁ + t₂ v_or= S₁ + S₂ S₁v₁ + S₂v₂
Orta sürət (v_or): zaman və sürətə görə, həmçinin yol və sürətə görə düsturlar
v_or=v₁ + v₂2
Cisim zamanın ilk yarısını v₁, ikinci yarısını v₂ sürətlə gedirsə orta sürət

3. Çevrə üzrə bərabərsürətli hərəkət

Cisim çevrə boyunca bərabər zaman fasilələrində bərabər qövslər cızır; bucaq sürəti, tezlik, period və sürət/təcil modulları sabit qalır.

🔎
φ=lR l=φ · R
Dönmə bucağı (φ, vahidi 1 rad) və qövs uzunluğu (l): [φ] = 1 rad — qövsün uzunluğu (l) çevrənin radiusuna (R) bərabər olduqda dönmə bucağı
rad=dərəcə ·π180° dərəcə=rad ·180°π
Dərəcə ilə radian arasında keçid; xüsusi hallar: 2π rad = 360°, 3π/2 rad = 270°, π rad = 180°, π/2 rad = 90°
T=tN T=1n N=tT
Dövrətmə periodu (T, vahidi 1 san): 1 tam dövrə sərf olunan zaman; t — zaman, N — dövrlərin sayı (adsız kəmiyyət), n — tezlik
n=1T n=Nt
Dövrətmə tezliyi (n): vahid zamandakı dövrlərin sayı; [n] = 1/san = san⁻¹ = Hs (Hers)
ω=ΔφΔt ω=2πT=2πn ω=2πNt
Bucaq sürəti (ω — omeqa): vahid zamanda radius vektorunun dönmə bucağı; [ω] = 1 rad/san, Δφ = ω · Δt
ω=φ'(t) Δφ=S_fiqur
Bucaq sürəti dönmə bucağının zamana görə törəməsidir; ω(t) qrafikinin zamanla əmələ gətirdiyi fiqurun sahəsi dönmə bucağına bərabərdir
v=lt v=2πRT=2πRn = ωR v=2πRNt
Xətti sürət (v): çevrəyə toxunan istiqamətdə yönəlir və radiusa perpendikulyardır; |v| = const
l=v · t = ωRt = 2πnRt l=2πRT· t = 2πRN
Bütün periodlarda qövs uzunluğu: t = T olduqda l = 2πR; t = T/2 olduqda l = πR; t = T/3 olduqda l = πR/1,5; t = T/4 olduqda l = πR/2; t = T/6 olduqda l = πR/3
v_yol=2πRT v_yerdəyişmə=S_yert
İstənilən periodda yola görə orta sürət (2πR / T) və yerdəyişməyə görə orta sürət (S_yer / t, burada t = l / v)
a=v²R=ω²R = 4π²n²R a=4π²RT²=4π²N²Rt²=ωv
Mərkəzəqaçma təcil (a): çevrənin mərkəzinə doğru yönəlir, xətti sürətə perpendikulyardır; |a| = const (həmçinin a = 2πnv = 2πv/T = 2πnω = 2πω/T)
n=√(tgα)2π T=2π√(tgα)=2π√(ctgα) ω=√(tgα)
a(R) qrafikinin meyl bucağına (tgα = a / R) görə tezlik (n), period (T) və bucaq sürətinin (ω) tapılması
Mərkəzdən/oxdan:T, n, ω, N, φ = const Radiusla artır:v, a, l
Mərkəzindən və ya diametrindən keçən ox ətrafında fırlanan disk/kürənin nöqtələrində: T₁=T₂=T₃, ω₁=ω₂=ω₃, n₁=n₂=n₃, N₁=N₂=N₃; mərkəzdən/oxdan uzaqlaşdıqca v, a, l artır
Qayışlı ötürmə:v, l = const T₁T₂=R₁R₂
Qayışlı ötürmədə (həmçinin bir-birinə toxunan disklər və dişli çarxlarda): v₁=v₂, l₁=l₂; yalnız T radiusla düz, (a, ω, n, N) radiusla tərs asılıdır: a₁/a₂ = ω₁/ω₂ = n₁/n₂ = N₁/N₂ = R₂/R₁
v₁ = v₂ > v₃|l₁ = l₂ > l₃ n₃ = n₂ > n₁|ω₃ = ω₂ > ω₁ T₃ = T₂ < T₁
Qayışla birləşmiş 1-ci və 2-ci çarxla eyni oxlu kiçik 3-cü çarxın qarışıq hərəkətində xətti, bucaq, period, tezlik və təcil əlaqələri

4. Nyutonun qanunları

Qüvvə, kütlə, sıxlıq, əvəzləyici qüvvə və cisimlərin qarşılıqlı təsiri arasındakı əsas qanunauyğunluqlar.

🔎
m=ρ · V ρ=mV
Kütlə (m, vahidi 1 kq), həcm (V) və sıxlıq (ρ, vahidi 1 kq/m³); verilmiş mayenin və bərk cismin sıxlığı onun kütləsi və həcmindən asılı deyil (ρ = const)
m=43πR³ρ ρ=3m4πR³ R=³√(3m / 4πρ)
Kürə formalı cisimlərin kütləsi, sıxlığı və radiusu
m=ρ · a³ ρ=ma³ a=³√(m / ρ)
Kub formalı cisimlərin kütləsi, sıxlığı və tili (a)
a=Fm F=m · a
Nyutonun II qanunu: [F] = 1 N = kq·m/san², [a] = 1 N/kq = 1 m/san²; kürə formalı cisimdə a = const olarsa F = (4/3)πR³ρa ⇒ F ~ R³
F₁=-F₂ a₁a₂=v₁v₂=S₁S₂=m₂m₁
Nyutonun III qanunu: təsir və əks-təsir qüvvələri eyni təbiətlidir, müxtəlif cisimlərə tətbiq olunduğundan bir-birini tarazlaşdıra bilməz
F_əv=F₁ + F₂ + ... F_əv=|F₁ - F₂|
Əvəzləyici qüvvə: eyni istiqamətli olduqda toplanır (F_əv,max), əks istiqamətli olduqda çıxılır (F_əv,min, böyük qüvvə istiqamətində yönəlir)
F_əv=√(F₁² + F₂²) F_əv=√(F₁² + F₂² + 2F₁F₂cosα)
Perpendikulyar (90°) və aralarında α bucağı əmələ gətirən qüvvələrin əvəzləyicisi; əvəzləyici qüvvə və təcil həmişə eyni istiqamətdə yönəlir
α = 120°⇒F_əv = F α = 60°⇒F_əv = F√3 α = 90°⇒F_əv = F√2
İki bərabər (F) qüvvənin əvəzləyicisinin tapılmasında xüsusi hallar — hər üç halda istiqaməti tənbölən boyunca yönəlir
a=Fₓm a=F · cosαm
Üfüqi səthdə sürət vektoru ilə α bucağı əmələ gətirən F qüvvəsinin təsiri ilə hərəkət edən cismin təcili
|F₁ - F₂| ≤ F_əv ≤ F₁ + F₂ F_əv,min = 0|F_əv,max = F₁ + F₂ + F₃
2 qüvvənin əvəzləyici aralığı; 3 qüvvədə |F₁ - F₂| ≤ F₃ ≤ F₁ + F₂ ödənərsə F_əv,min = 0, ödənməzsə F_əv,min = böyük qüvvə - digər 2 qüvvənin cəmi
F=(m₁ + m₂) · a T=m₁m₁ + m₂· F
İplə bağlanmış cisimlərin üfüqi sürtünməsiz səthdə hərəkəti (məs: m və 4m üçün F = 5ma, T = F/5; m, 2m, 3m üçün T₁ = F/6, T₂ = F/2)
T=2m₁m₂m₁ + m₂· g a=m₁ - m₂m₁ + m₂· g
Tərpənməz blokdan keçirilmiş cisimlər (m₁ > m₂, v₀ = 0, F_sürt = 0, P_blok = 0): ipdəki gərilmə qüvvəsi (T) və sistemin təcili (a); təcillər verilərsə a = a₁a₂ / (a₁ + a₂)
S=at²2 l = 2S=at² v₁,₂ = v₂,₁=2v = 2at
Tərpənməz blokda yüklərin yerdəyişməsi (S), cisimlər arasındakı şaquli məsafə (l) və bir-birinə nəzərən nisbi sürəti
T₁=(m₁ + m₂ + m₃)(g + a) T₄=(m₄ + m₅)(g - a)
Tərpənməz blokda ardıcıl asılmış yüklərdə ip gərilməsi: yuxarı qalxan tərəfdə T₂ = (m₂ + m₃)(g + a), T₃ = m₃(g + a); aşağı enən tərəfdə T₅ = m₅(g - a) və T₁ = T₄
F=m ·v - v₀t=m ·v² - v₀²2S (v₀ = 0): F=m ·vt=m ·2St²=m ·v²2S
Bərabərtəcilli hərəkətdə Nyutonun II qanununun ifadələri
F=ma = mv²R=mω²R = m·4π²n²R F=m ·4π²RT²=mωv
Çevrə üzrə bərabərsürətli hərəkətdə mərkəzəqaçma qüvvəsi (əvəzləyici qüvvə çevrənin mərkəzinə yönəlir)

5. Ümumdünya cazibə qanunu

Cisimlərin qravitasiya qarşılıqlı təsiri, ağırlıq qüvvəsi və sərbəstdüşmə təcilinin hündürlükdən asılılığı, şaquli hərəkətlər, Kepler qanunu və kosmik sürətlər.

🔎
F=G ·m₁ · m₂r² G=F · r²m₁ · m₂
İki cismin cazibə qüvvəsi: m₁, m₂ — kütlələr, r — mərkəzlər arası məsafə, G — qravitasiya sabiti ([G] = 6,67·10⁻¹¹ N·m²/kq² = m³/(kq·san²)); iki toxunan kürə üçün F ~ R⁴
F_ağ=m · g = ρ · V · g g=F_ağm
Ağırlıq qüvvəsi (F_ağ) və sərbəstdüşmə təcili / qravitasiya sahəsinin intensivliyi (g, [g] = 1 N/kq = 1 m/san²); g cismin kütləsindən (m) asılı deyil
F₀=G ·M · mR² g₀=G ·MR²=43GρπR
Cisim planetin (Yerin) səthində olduqda ağırlıq qüvvəsi (F₀) və sərbəstdüşmə təcili (g₀); M — planetin kütləsi, R — radiusu
F=G ·M · m(R + h)² g=G ·M(R + h)²
Planet səthindən h hündürlükdə ağırlıq qüvvəsi və sərbəstdüşmə təcili (h artdıqca F və g azalır)
g=g₀(h/R + 1)² F=F₀(h/R + 1)²=mg(h/R + 1)²
Səth ilə h hündürlüyü arasında əlaqə: h = R olduqda g₀/4, F₀/4; h = 2R olduqda g₀/9, F₀/9; h = 3R olduqda g₀/16, F₀/16
v=v₀ - gt=√(v₀² - 2gh) h=v₀t -gt²2=v₀² - v²2g h=v + v₀2· t
Şaquli yuxarı atılmış cismin müəyyən andakı sürəti və yerdən hündürlüyü (a = g = const)
t_q=v₀g=√2h_maxg=2h_maxv₀ t_uç = 2t_q=2v₀g=√8h_maxg=4h_maxv₀
Şaquli yuxarı atılmış cismin qalxma müddəti (t_q) və uçuş müddəti (t_uç)
h_max=v₀²2g=gt_q²2=gt_uç²8=v₀t_q2 hₙ=v₀ -g(2n - 1)2
Maksimal qalxma hündürlüyü (h_max) və n-ci saniyədə gedilən yol (hₙ)
l_uç = 2h_max=v₀²g=gt_q²=gt_uç²4 (t > t_q): l=h_max +g(t - t_q)²2
Şaquli yuxarı atılmış cismin uçuş müddətində və t > t_q müddətində qət etdiyi ümumi yol
v=v₀ + gt = √(v₀² + 2gh) h=v₀t +gt²2=v² - v₀²2g h=v + v₀2· t
